# 					                                                           **数据和基本数据类型**

## 一、数据

1. **数据：承载信息的符号** ；**表达式：操作数据对象的方法**。
2. 按照在程序执行时数据是否会发生变化分类：不变的称为**常量**（***constant***），反之则称为**变量**（***variable***）。
3. 对于常量来说**`（1,2,-3,3.14）`**这些计算机很好区分它们的基本数据类型；
4. 但是对于用字母表示的数`（a,b,c,x,y）`计算机很难区分。
5. 因此，引入**数据类型关键字**，在定义时就指定其类型。
6. **关键字：在C语言中有特殊意义的字符或字符串**

##### **关键字（12+20）：**

###### 	类型修饰与定义（3）：

| 关键字         | 核心用途与说明                                               |
| :------------- | :----------------------------------------------------------- |
| **`typedef`**  | **类型定义**。为现有类型创建别名，提高代码可读性。如：`typedef int Length;` |
| **`const`**    | **常量限定**。修饰的变量值不可变，是重要的安全机制。         |
| **`volatile`** | **易变性限定**。告诉编译器该变量可能被外部因素改变，禁止优化，用于硬件编程。 |

###### 	流程控制（12）：

| 关键字                                    | 核心用途与说明                                          |
| :---------------------------------------- | :------------------------------------------------------ |
| **`if`** / **`else`**                     | 条件分支。                                              |
| **`switch`** / **`case`** / **`default`** | 多路选择。`switch`判断，`case`匹配，`default`默认情况。 |
| **`for`** / **`while`** / **`do`**        | 循环控制。`do...while`至少执行一次。                    |
| **`break`**                               | 跳出当前循环或`switch`语句。                            |
| **`continue`**                            | 跳过本次循环剩余代码，直接开始下一次循环。              |
| **`goto`**                                | 无条件跳转到标签处。**慎用**，会破坏程序结构。          |
| **`return`**                              | 从函数中返回值，并结束函数执行。                        |

###### 	函数与存储类别（5）：

| 关键字             | 核心用途与说明                                               |
| :----------------- | :----------------------------------------------------------- |
| **`auto`**         | **自动存储期**。默认的局部变量存储类别，通常省略。           |
| **`register`**     | **建议编译器将变量存储在CPU寄存器中**（仅是建议，现代编译器优化已很智能）。 |
| **`static`**       | **静态**。修饰局部变量时使其生命周期延长至程序全程；修饰全局变量或函数时限制其作用域为当前文件。 |
| **`extern`**       | **外部引用声明**。声明变量或函数定义在别的文件中，用于链接。 |
| **`inline`** (C99) | **内联函数建议**。建议编译器将函数代码在调用处展开，以空间换时间。 |

------

[^位（bit）]:        最小的储存单元，储存1或0
[^字节（byte）]: 计算机储存单位，1byte  = 8bit
[^字（word）  ]:  设计计算机时给定的**自然存储单位**，是计算机一次性最多能处理数据的长度
[^整数和浮点数]:  根据数据在计算机里的储存方式不同，又将上面有关键字所定义的数据分为**整数**和**浮点数**。且浮点数表示数的范围比整数大。

## **二、整型**

**{ 数据对象：整数集的一个有限子集**

**操作：算数、自增、位运算、比较、赋值、类型、函数**

**}**

1.**int**（16或32位，根据自然储存单位决定） 型变量的操作

```c
1 2 3 -1;          //整型常量
int a,b;           //声明int变量：a,b
int c = 1,d = 3;   //定义并初始化int变量：c,d
c = 5,d = 6；       //赋值
```

[^initialize]: 指在定义时就对定义的变量赋初始值
[^declaration]: 告诉编译器所声明的对象有定义

2.其他整型（**与类型关键字结合**）：

**short int**：16位

**long int** ：32位

**long long int(c99)**：64位

**unsigned int** ：32位

**unsigned long int (c90)** ：32位

**unsigned short int(c90)** ：16位

**unsigned long long (c99)**：64位

int -> long  -> unsigned long -> long long -> unsigned long long

## **三、字符型（本质上是一个特殊的整型）**

**{ 数据对象：整数集的一个有限子集**

**无符号：[0,255]，有符号：[-128,127]**

**操作：算数运算、比较运算、输入输出、类型转换、位运算、函数**

**}**

一个字符在内存中通常占8位

```c
'a' 'b' 'A'              //字符常量表示要用''引起来防止和变量混淆
char ch1,ch2;            //声明char型变量：ch1,ch2
char ch1 = 'a',ch2 = 'A';//定义并用字符常量初始化char型变量：ch1,ch2
```

## **四、浮点型**

**{ 数据对象：实数集的一个有限子集**

**操作：算数、比较、赋值、类型转换、函数**

**}**

1.**float**型（32位）变量操作

```c
3.14159 2.71828;       //浮点常量
float a,b,c;           //声明float型变量：a,b,c
float m = 3.5, n = 5.6;//定义并初始化float型变量：m,n
m = 3.1415,n = 2.71828;//赋值
```

2.其他浮点型（**与类型关键字结合**）：

**double** ：64位

**long double**：  64、128位
