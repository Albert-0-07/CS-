#                                                 **结构数据类型（C基础版）**

#### 注：

#### 1.要构造结构数据类型的常量则需要在对应的数据类型说明符前加"`const`"修饰："`const double * pd`" ，* 前面的"const double"代表该地址储存的变量是“常量”，不可以被修改的，即该指针是指向 const 的。

####         2.利用"`const`"可以在函数中保护传进来的参数不被修改。

####         4.用"`const`"修饰的指针变量"`const dobule * pd`"不能修改其指向的值，但是它的地址可以修改。

## **一、指针类型**

**{ 数据对象：内存地址（大部分操作系统中用无符号整数表示）**

**操作：取地址（&）、间接寻址（*）、自增**

**动态内存分配、数组运算**

**}**

### 1.基本指针变量操作

定义指针类型变量的一般形式：
类型名 * 标识符 

 **注：* 表示其后面标识符所代表的变量的类型是指针类型，前面的是该地址存储变量的类型。**

```c
int * p1 ,* p2;      //声明整型指针变量
char * pstr1,* pstr2;//声明字符型指针变量
float * p;           //声明浮点型指针变量

/*
定义指针类型变量的一般形式：
类型名 * 标识符 ; 注：* 表示其后面标识符所代表的变量的类型是指针类型，前面的是该地址存储变量的类型。
*/

//定义并初始化
int * p = &a;
char * pstr = &ch;
float * p2 = &x;
```

## **二、数组类型**

**{ 数据对象：具有相同类型的数据元素** 

**（包括简单和复杂类型，即基础和结构类型）**

**操作：读取、赋值**

**}**  

### **1.基本数组变量的操作（以一维数组为例）**

```c
int   a[10],b[5];                  //声明int型数组变量：a、b
float x[10],y[10];                 //声明float型数组变量：x、y
char  ch1[10],ch2[5];              //声明char型数组变量：ch1、ch2
//定义并初始化数组
int   a[10]  = {0},b[] = {0,1,2};   
float x[5]   = {0},y[] = {3.45,2.1};
char  ch1[5] = {'a','A','C','v','d'};
char  ch2[]  = {'s'};              
/*
声明的一般形式：
类型名 标识名[大小] 
若在类型名前面加"const"修饰，则数组在初始话值后，数组元素便不能修改了
*/
```

 **注：**C99之前方括号中的大小只能是**整型常量表达式**，即以下的数组定义是不合法的：`float x[n],y[n];`

**{ 数据对象：字符构成的有限序列。**

**操作：类比char 数组操作、函数库操作（`string.h`）**

**}**


## 四、结构体类型

- ####  当数据和操作它的函数分散各处时，维护会变成灾难。于是，人们自然地将**紧密相关的数据**和**操作这些数据的函数**绑定在一起，形成一个逻辑单元，这就是 **“模块”** 或 **“类”** 的雏形。

**{ 数据对象：不同数据对象的有序集合**

**操作：初始化、引用、赋值**

**}**

### **1.构建结构体变量**

```c
//声明一个结构体变量
struct Students{
    int age;
    char * name;
    char * id;
};
//定义并初始化结构体变量：stu1
struct Students stu1 = {18,"Huali","20250101"};
//或者声明的同时定义结构体变量
struct Students{
    int age;
    char * name;
    char * id;
}stu1;
```

### 2.访问结构体变量的成员用**圆点符“.”** ，**变量名.成员名**：

```c
struct Students{
    int age;
    char * name;
    char * id;
}stu1;
int a = stu1.age;
char * pst = stu.name;
```

### **3.结构体的特别之处：**

结构体是对一类数据对象的抽象，因此统一用标识名"`struct`"；但是作为每一个具体的结构体变量它们的结构却又大不相同，因此"`struct`"后面还要跟能具体代表这一结构的**类型名**

### 4.**typedef:**

 为了使代码更具可读性以及结构体变量的定义更符合之前数据类型变量的定义，引入"**typedef**"重定义对应的数据类型名

```c
//因此上述对结构体变量的声明、定义和初始化可以改为：
typedef struct Students{
    int age;
    char * name;
    char * id;
}STU;                        //STU 为 sturct Students 数据类型的类型名
STU stu1 = {18,"Huali","20250101"};
//或者：
struct Students{
    int age;
    char * name;
    char * id;
};
typedef struct Students STU;
STU stu1 = {18,"Huali","20250101"};
```
