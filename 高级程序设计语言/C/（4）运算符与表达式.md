# **运算符与表达式**

## 注：

### 1.作用：用来操作数据与数据对象

## 一、运算符

### 1.赋值运算符： **=** 

- #### **对象** **：** 用于储存值的数据存储区域

- #### **左值与可修改的左值：** 

  - **左值**是早期C语言，在`const` 修饰符出来之前的概念，**用于表示或定位储存位置（对象）的标签**

  ​	1.一个对象，它可以**引用内存中的地址**

  ​	2.可以放在赋值号的左侧

  - **可修改的左值**（对象定位值：用于表示可修改的值）是在`const`修饰符出来之后，排除那些用`const`修饰的不可更改的变量
  - 变量名、数组元素、结构体成员、指针表达式。

- #### **右值：** 能赋值给左值的量且本身不是左值，（表达式的值）。

### 2.运算符优先级与结合性

- 优先级：解决**不同运算符谁先预算**的问题
- 结合性：解决**相同运算符计算顺序**的问题

| 优先级 | 运算符                       | 名称/描述                             | 结合性 |
| :----- | :--------------------------- | :------------------------------------ | :----- |
| 1      | `()` `[]` `.` `->` `++` `--` | 括号、数组下标、成员访问、后置自增/减 | 左→右  |
| 2      | `!` `~` `++` `--` `+` `-`    | 逻辑非、按位取反、前置自增/减、正负号 | 右→左  |
|        | `(type)` `*` `&` `sizeof`    | 强制类型转换、解引用、取地址、求大小  |        |
| 3      | `*` `/` `%`                  | 乘法、除法、取模                      | 左→右  |
| 4      | `+` `-`                      | 加法、减法                            | 左→右  |
| 5      | `<<` `>>`                    | 左移、右移                            | 左→右  |
| 6      | `<` `<=` `>` `>=`            | 关系运算符                            | 左→右  |
| 7      | `==` `!=`                    | 相等性判断                            | 左→右  |
| 8      | `&`                          | 按位与                                | 左→右  |
| 9      | `^`                          | 按位异或                              | 左→右  |
| 10     | `|`                          | 按位或                                | 左→右  |
| 11     | `&&`                         | 逻辑与                                | 左→右  |
| 12     | `||`                         | 逻辑或                                | 左→右  |
| 13     | `?:`                         | 条件运算符（三元运算符）              | 右→左  |
| 14     | `=` `+=` `-=` `*=` `/=` `%=` | 赋值运算符                            | 右→左  |
|        | `&=` `^=` `|=` `<<=` `>>=`   |                                       |        |
| 15     | `,`                          | 逗号运算符                            | 左→右  |

## 二、表达式和语句

### 1.表达式：

- **每个表达式都有一个值**
- 由运算符和数据构成的用作计算的式子

### 2.语句：

- ##### 表达式语句：

  在任何合法的C表达式后加上`;` 

- ##### 复合语句：

  用`{}` 括起来的语句，其中可以为空语句

- ##### 控制语句：

  - **选择语句：** `if`、`if...else`、`if...else if...else`、`switch`
  - **循环语句：** `while`、`for`、`do...while`、

- ##### 跳转语句：

  `goto`、`break`、`continue`、`return`
