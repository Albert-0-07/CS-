#                                                                                                                          **文件和文件操作**

#### 3.从硬件层面来看文件操作：

- **总线（Bus）**：文件的每一个字节从磁盘到内存，都必须通过**系统总线**和**I/O总线**“搬运”。理解总线带宽和时序，能让你明白为何大文件读写慢，以及内存映射文件等高级优化技术的原理。
- **输入输出系统**：
  - **程序控制I/O**：CPU原地等待慢速的磁盘操作，效率极低。
  - **中断驱动I/O**：磁盘完成操作后，“打断”CPU，通知其回来处理。这提高了CPU利用率。
  - **直接内存访问（DMA）**：这是现代系统的关键！一个专门的**DMA控制器**接管数据搬运，无需CPU插手，彻底解放CPU。文件读写性能因此大幅提升。
- **存储层次结构**：文件操作是**缓存**理念的集大成者。操作系统会动用**多级缓存**（磁盘缓存、页缓存）来加速文件访问。理解“**局部性原理**”，你就明白了为何顺序读写通常比随机读写快得多。

#### 4.API与抽象硬件接口：

- 你的程序调用 `fwrite()`，这是**C标准库API**。
- `fwrite()` 可能会调用 `write()`，这是**操作系统提供的系统调用API**。
- 请求进入内核，经过**虚拟文件系统**，它是一个巨大的**抽象接口层**，定义了文件操作的统一方法。
- VFS将请求转给具体的**文件系统**（如ext4）。
- 文件系统将操作转换为对“块设备”的请求，通过**块设备抽象层**（另一套**抽象硬件接口**）发出。
- 块设备层调用具体的**磁盘驱动程序**。驱动程序**直接与硬件对话**，但它通过实现操作系统定义的**抽象硬件接口**来接入系统。
- 驱动程序操作**物理磁盘控制器**，完成写入。

#### 5.信息处理系统的几个根本原则：

- **信息与载体的分离**：信息（程序/遗传信息）独立于处理它的物理硬件（机器/细胞器）。
- **基于规则的确定性过程**（在理想状态下）：每一步操作都由当前输入和状态唯一确定。
- **过程的普适性**：同一台通用图灵机可通过更换纸带程序解决不同问题；同一套翻译机制可通过读取不同的mRNA合成不同的蛋白质。这体现了 **“通用性”**。
- **从符号到实体的转换**：图灵机将符号序列转换为新的符号序列；细胞将核苷酸序列（信息）转换为氨基酸序列（功能分子），是**信息到功能的转变**。

####  6.图灵机与冯诺依曼架构：

- **图灵机**是**理论模型**，回答了“计算是什么”和“什么是可计算的”。
- **冯·诺依曼架构**是**工程实现方案**，回答了“如何建造一台实用的、通用（图灵完备）的计算机”。
- 可以说，**冯·诺依曼架构是在工程上对“通用图灵机”思想的一种最优实现**。它用“内存”替代了“纸带”，用“CPU”替代了“读写头”和“规则表”，用“总线”实现了移动。

## 一、图灵机

1. **一条无限长的纸带**：被划分为连续的格子，每个格子可以写入一个来自有限“字母表”的符号（如 `0`, `1` 或空白）。
2. **一个读写头**：每次对准纸带上的一个格子，可以：
   - **读取**当前格子的符号。
   - **写入**一个新的符号覆盖当前格子。
   - **向左或向右移动**一格。
3. **一个状态寄存器**：记录机器当前的“状态”（如“状态A”、“状态B”）。状态数量有限，其中包含一个特殊的**开始状态**和若干个**终止状态（如接受/拒绝状态）**。
4. **一套控制规则表（程序）** 这是机器的“大脑”。它是一条条形如 **“如果在状态Q，读到符号S，那么写入符号S'，将头移动方向D，并切换到新状态Q'”** 的指令集合。机器根据当前状态和读到的符号，查这张表决定下一步行动

* **中央处理器（CPU）的指挥角色**：CPU执行你程序中的文件操作代码，但**它并不直接处理磁盘上的数据**。它通过发出指令，指挥一个专门的 **“I/O控制器”**（如磁盘控制器）去完成实际的读写。这体现了冯·诺依曼架构中“控制器”的概念。

## 三、文件

- 其本质上是存储在“**外存储器”（磁盘/SSD）上的有序数据集合**。当它被读入“主存储器”（内存）后，才能被CPU处理。
- **流：** 它是一个**位于内存中的双向数据通道** ， 用以最小化CPU等待I/O的空转时间，将不可预测的硬件操作转化为可预测的内存操作。
- **缓存：** 一种通过将数据**临时存储在访问速度更快的介质/位置**中，**以减少访问延迟、提升系统整体效率**的机制。其核心设计思想是：**利用更充裕的存储空间，来换取更宝贵的时间资源**，设计初衷是为了**解决不同硬件通信速度不一样而带来的计算资源浪费**的问题。

## 四、文件操作

- 文件操作，核心就是数据在这**两级存储（内存和外存）间移动和管理的过程**。

- 绝对路径：从根目录上开始检索的

- 相对路径：从当前目录开始检索的

  `.` （一个点）：代表**当前目录**。

  `..` （两个点）：代表**上级目录**。显示当前读写位置

- 文件指针“`FILE*`” ：**文件操作的对象**

- **文件位置指针：**  **当前文件读写位置** 

  - fseek：   设置文件位置指针的位置

    ​                 函数原型：int fseek(FILE *stream, long int offset, int whence);

  - ftell：      返回当前文件位置指针的位置（相对于文件开头的偏移量）

    ​                 函数原型：long int ftell(FILE *stream);

  - rewind： 将文件位置指针重新设置到文件开头.

    ​                  函数原型：void rewind(FILE *stream);

  - fgetpos：获取当前文件位置指针的位置（使用fpos_t类型，适用于大文件）

    ​                  函数原型：int fgetpos(FILE *stream, fpos_t *pos);

  - fsetpos：设置文件位置指针的位置（使用fpos_t类型，适用于大文件）

    ​                  函数原型：int fsetpos(FILE *stream, const fpos_t *pos);

#include <stdio.h>
#include <stdbool.h>
#include <string.h> 

/* 
打开方式：
		r  只读，若文件不存在则打开失败，反之打开成功 
        r+ 可读可写，从文件头开始写，一般用来做修改 
        w  只写，若文件不存在则创建文件并打开，反之清空文件后打开
        w+ 可写可读，若文件不存在则新建文件从回头开始写，
        反之则清空文件内容后，从头开始写入数据，读出的是写入的数据 
		
		字符输入输出：fputc(),fgetc()
		字符串输入输出： fputs(),fgets() 
*/

//只读方式打开文件 
void fileOpen(){
	FILE * fp = fopen("./fileTest/helloWorld.txt","r");
	if(fp == NULL){
		perror("flie open failed");
			return;
	}
	while(true){
	char ch = fgetc(fp);
	if(ch == EOF) break;
	printf("%c",ch);	
	}
	fclose(fp);
} 

//只写方式打开文件
void fileWrite(){
	FILE * fp = fopen("helloWorld.txt","w");
	if(fp == NULL){
		perror("flie open failed");
			return;
	}
	int i;
	char * str = "Hello World!";
	for(i = 0 ; i < strlen(str) ;i++){
		char ch = fputc(str[i],fp);
		//printf("%c",ch);	
	}
	fclose(fp);
} 

//可写可读的方式打开文件
void fileReadWrite(){
	FILE * fp = fopen("helloWorld.txt","w+");
	if(fp == NULL){
		perror("flie open failed");
			return;
	}
	char buf[128];
	fputs("你好",fp);
	rewind(fp);
	fgets(buf,sizeof(buf),fp);
	puts(buf); 
	fclose(fp);	
}

//格式化输入输出 
void fileFormatWrite(){
	FILE * fp = fopen("helloWorld.txt","w+");
	if(fp == NULL){
		perror("flie open failed");
			return;
	}
	char buf[128]; 
	fprintf(fp,"%s","nihao");
	rewind(fp);
	fscanf(fp,"%s",buf);
	puts(buf);
}
